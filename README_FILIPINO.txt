CHOWKI Android App project

Included:
- CHOWKI logo loading screen
- Muted looping video banner at the top of the app
- Background audio extracted from the supplied video, starts automatically when the shop opens and loops while the app is in the foreground
- WebView for https://chowki.netlify.app/
- Android file chooser support for uploading receipts

NOTE: This is Android source code, not a compiled/installable APK. Build with Android Studio/Gradle to create the APK. Audio is paused when the app goes into the background and resumes when the app returns to the foreground.
